O número grande é a parte do código do jogo japonês (versão 983) que o nosso código-fonte, depois de compilado, reproduz de forma idêntica, medida em bytes. “Com quase iguais” soma as funções que só diferem em detalhes (ordem de instruções, registradores). O objetivo final é o jogo funcionar igual, não chegar a 100% aqui.

As frentes de trabalho · cada uma é uma fila automática que roda sozinha, em paralelo

O que importa para o jogo funcionar

O critério é o jogo funcionar como o original: todo arquivo compilando, toda função escrita e as estruturas de dados com o tamanho certo. Função “escrita” = já existe no nosso código e foi achada no 983 (igual, quase igual ou diferente só no jeito de compilar).
